# 分级数据安全管控策略管理与自适应策略绑定系统
- *Hierarchical Data Security Control Policy Management and Adaptive Policy Binding System*

## 项目简介

本项目目标在于实现策略模板管理，资产分级完成后自动绑定对应安全管控规则，不同分级数据匹配不同安全策略：
1. 分级安全策略模板库：预设 4 级数据配套策略：核心数据禁止外发、重要数据强制脱敏、一般数据内部受控共享、公开数据无限制。支持自定义新增策略。
2. 策略自动绑定：资产完成分级后，依据分级结果自动匹配管控策略；支持人工修改单资产策略。
3. 策略详情查看：查看资产绑定的访问控制、水印、脱敏、外发限制要求。
4. 策略影响评估：统计每种策略覆盖多少资产，评估管控范围。
5. 策略测试验证：测试不同分级资产策略匹配逻辑正确性。
